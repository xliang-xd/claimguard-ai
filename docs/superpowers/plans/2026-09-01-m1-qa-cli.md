# M1 QA CLI 实施记录

## 目标

构建首个端到端 QA CLI：读取文字对话 fixture，加载 V1 规则目录，并生成结构化质量报告。

## 交付内容

- `src/claimguard/conversation.py`：对话与消息模型、JSON fixture 加载。
- `src/claimguard/qa.py`：确定性 QA 报告模型和生成器。
- `src/claimguard/cli.py`：针对 fixture 的命令行入口。
- `tests/test_conversation.py`、`tests/test_qa_report.py`、`tests/test_cli.py`：加载、报告契约和 CLI JSON 输出覆盖。
- README 与 `docs/m1-qa-cli.md`：运行方式及能力边界说明。

## 实施约束

M1 保持确定性和本地运行：不引入外部运行时依赖、LLM 或 RAG 调用。报告包括得分、结论、证据片段和占位建议，以便后续模型能力可针对稳定契约测试。

## 验证

```bash
python3 -m unittest discover -s tests
PYTHONPATH=src python3 -m claimguard.cli examples/conversations/claim-amount-dispute.json
```

重要变更需在测试通过后提交并推送；面向用户的能力完成前必须同步更新文档。
