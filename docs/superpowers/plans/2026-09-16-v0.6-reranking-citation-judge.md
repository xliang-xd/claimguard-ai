# v0.6 Reranking 与 Citation Judge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Policy Copilot 仅在本轮真实检索证据经 Reranking 和 Citation Judge 验证支持时交付客服草稿。

**Architecture:** Policy Tool 进行 Embedding 召回、Reranking 和阈值过滤，并把选中条款写入仅内存的 Evidence Ledger。Runtime 对每个 `draft_ready` 调用 Citation Judge；只有 verdict 为 `supported` 且引用属于本轮 Ledger 时才保存会话并交付草稿。

**Tech Stack:** Python 3.10+、Qwen Model Studio、OpenAI Agents SDK、Pydantic、标准库 `unittest`、Fireworks Tech Graph。

**Spec:** `docs/superpowers/specs/2026-09-16-v0.6-reranking-citation-judge-design.md`

## Global Constraints

- 所有推理、Embedding、Reranking 和 Judge 使用 Qwen；不引入境外 provider。
- OpenAI 托管 tracing 默认关闭；测试不得访问网络。
- 审计不得包含 API Key、Authorization、URL 参数、原始客户消息、草稿正文或条款正文。
- Citation 失败、无证据、未知引用、无效结构化输出或异常均返回空草稿的 `human_takeover`，且不保存成功会话。
- 所有新增说明文本使用中文；版本升级为 `0.6.0`。

```python
CitationStatus = Literal["supported", "unsupported", "insufficient_evidence"]

@dataclass(frozen=True)
class CitationVerdict:
    status: CitationStatus
    citations: tuple[str, ...]
    reason_code: str

class CitationJudge(Protocol):
    def judge(self, draft: str, evidence: tuple[EvidenceRecord, ...]) -> CitationVerdict: ...
```

`supported` 必须有且仅能有 Ledger 中的引用 ID；其余状态不得有引用。`QwenCitationJudge` 使用 Qwen 兼容客户端请求严格 JSON；响应、草稿、条款正文、URL 和凭据永不出现在异常消息中。
