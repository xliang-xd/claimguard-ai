# v0.3 RAG 依据能力实施记录

## 目标

为五条中文知识依据规则增加合成保单条款检索，并将可追溯条款证据附加到 QA 报告，同时维持默认 QA 命令离线且兼容。

## 工作项

1. 实现中文保单 Markdown 解析、`PolicyClause`、可验证的本地 JSON 索引与余弦检索。
2. 接入阿里云 Model Studio `qwen3.7-text-embedding`，仅用于显式索引创建与 `--index` 检索。
3. 为 `RAG-001` 至 `RAG-005` 增加中文检测和 `GroundingEvidence`。
4. 扩展 CLI：`index <policy.md> --output <index.json>` 与 `<conversation.json> --index <index.json>`。
5. 增加离线测试、中文 fixture、README、架构/编排图、M3 文档和版本记录。

## 约束与验证

API Key、`.env` 和 `.claimguard/` 产物不得提交；自动测试使用注入的本地向量，绝不调用远程 API。手动运行可使用：

```bash
PYTHONPATH=src python3 -m claimguard.cli index data/knowledge/petcare-plus-policy-zh.md --output .claimguard/petcare-plus-policy.json
PYTHONPATH=src python3 -m claimguard.cli examples/conversations/zh-deductible-dispute.json --index .claimguard/petcare-plus-policy.json
python3 -m unittest discover -s tests
```

本阶段发布为 `v0.3.0`；Reranking、LLM Judge、Copilot、持久化和 Web/API 不在范围内。
