# v0.4 Semantic QA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add opt-in, structured Qwen semantic QA findings to completed-conversation reports without changing offline deterministic behavior.

**Architecture:** A standard-library HTTP client calls `qwen3.7-plus` once only when the CLI receives `--llm`. The client enforces a strict judge-response contract; the QA layer accepts only quote-backed violations and deduplicates against deterministic findings. Existing RAG grounding remains independent and optional.

**Tech Stack:** Python 3.9+, dataclasses, `urllib.request`, JSON Schema request payloads, Alibaba Cloud Model Studio OpenAI-compatible endpoint, `unittest` and injected transports.

**Spec:** `docs/superpowers/specs/2026-09-04-v0.4-semantic-qa-design.md`

## Global Constraints

- Keep Python compatibility at `>=3.9`; use `Optional[...]`, not PEP 604 unions.
- Read credentials only through existing local configuration. Never log, serialize, or commit `DASHSCOPE_API_KEY`.
- Automated tests must use injected transports and literal responses; they must never call Model Studio.
- Preserve legacy `generate_qa_report(conversation, catalog)` output and CLI behavior when `--llm` is absent.
- Invoke the semantic judge once per completed conversation only when `--llm` is supplied.
- Use `qwen3.7-plus`, `temperature: 0`, `enable_thinking: false`, and strict JSON Schema by default; `CLAIMGUARD_SEMANTIC_MODEL` overrides the model locally.
- Treat citation judgment, reranking, Copilot generation, persistent storage, and web/API endpoints as deferred.
- Additive report fields must serialize as `null` on non-LLM findings.

## File Structure

- `src/claimguard/semantic_judge.py`: semantic client protocol, judge-response dataclasses, request builder, response parser, and provider error boundary.
- `src/claimguard/config.py`: add the local semantic-model configuration name.
- `src/claimguard/qa.py`: validate judge findings against the transcript, deduplicate them, and add them to the stable report.
- `src/claimguard/cli.py`: add `--llm` and construct the client only on that path.
- `tests/test_semantic_judge.py`: request shape, JSON parser, and secret-safe error tests.
- `tests/test_qa_report.py`: semantic merging, duplicate, and fabricated-evidence behavior.
- `tests/test_cli.py`: offline default, lazy `--llm`, and semantic error behavior.
- `examples/conversations/zh-semantic-qa.json`: a Chinese fixture covering the semantic-rule matrix.
- `README.md`, `docs/architecture.md`, `docs/agent-orchestration.md`, `docs/versioning.md`, `docs/m4-semantic-qa.md`, `docs/assets/*.svg`, `docs/assets/*.png`: current capability, operator command, roadmap, and release documentation.

- [ ] **Step 3: Add the local model setting and client types**

Implement the following public contract:

```python
@dataclass(frozen=True)
class SemanticJudgment:
    rule_id: str
    violated: bool
    evidence: str
    reasoning: str
    recommendation: str
    confidence: str

class SemanticJudgeClient(Protocol):
    def judge(self, conversation: Conversation) -> list[SemanticJudgment]:
        ...
```

Add `CLAIMGUARD_SEMANTIC_MODEL` to `LOCAL_CONFIGURATION_NAMES` and
`.env.example`. Default it to `qwen3.7-plus`. Reuse
`CLAIMGUARD_DASHSCOPE_BASE_URL`, `DASHSCOPE_API_KEY`, and the existing 30-second
timeout. POST to `<base-url>/chat/completions` with `Authorization: Bearer`.

The request's JSON Schema allows only `SEM-002` through `SEM-005`, exactly one
entry per rule, confidence `high|medium|low`, and no extra keys. The system
instruction is Chinese and requires an exact agent quote for a violation.

- [ ] **Step 4: Parse only complete, valid responses**

Read `choices[0].message.content` as JSON. Reject non-JSON, missing fields,
duplicate IDs, unsupported IDs, invalid confidence, non-boolean `violated`, or
violated entries with blank evidence/reasoning/recommendation. Require blank
evidence/reasoning/recommendation on non-violations. Convert HTTP, URL, decode,
and contract failures to `SemanticJudgeError` without embedding credentials in
the message.
