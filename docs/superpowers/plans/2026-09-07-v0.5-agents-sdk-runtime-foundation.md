# v0.5 Agents SDK 运行时基础实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改变现有 QA CLI 的前提下，引入 OpenAI Agents SDK、Qwen ModelProvider、本地状态与审计接口，并交付可运行的 `Router -> Policy Agent` 最小 Handoff。

**Architecture:** OpenAI Agents SDK 负责 Agent、Handoff、Runner 和 tracing 开关；Model Studio 的 OpenAI-compatible Responses API 通过独立 `QwenModelProvider` 接入。现有知识索引和 Embedding 客户端作为 Policy Agent 的只读工具复用，应用层保存当前 Agent 和本地审计事件。

**Tech Stack:** Python 3.10+、`openai-agents`、Model Studio Responses API、Qwen、`unittest`、现有本地 JSON 知识索引和 JSONL 审计文件。

**Spec:** `docs/superpowers/specs/2026-09-07-agents-sdk-copilot-architecture-design.md`

## Global Constraints

- 所有推理和 Embedding 模型默认使用中国大陆地域的 Qwen 服务。
- OpenAI 托管 tracing 默认关闭；本地结构化审计始终开启。
- API Key 只从被忽略的 `.env` 或进程环境读取，不能进入输出、异常、fixture 或 Git。
- 第一版按单组织运行，但所有运行上下文保留 `tenant_id`、`user_id` 和 `session_id`。
- Router 只负责 Handoff，不回答复杂保险问题。
- `v0.5.0` 只实现 `Router -> Policy Agent`；Claims、Complaint、人工审批和副作用工具保持未启用。
- 现有 QA CLI 的默认离线行为和报告契约不得改变。
- 每个任务采用 TDD：先观察失败测试，再写最小实现，最后运行相关测试和完整测试。

class AgentRuntimeSettings:

    base_url: str
    router_model: str

class AgentSettingsError(ValueError):
    pass


def load_agent_runtime_settings(
    environment: Mapping[str, str] | None = None,
) -> AgentRuntimeSettings:
    source = os.environ if environment is None else environment
    return AgentRuntimeSettings(
        api_key=_required(source, "DASHSCOPE_API_KEY"),
        base_url=_value(source, "CLAIMGUARD_DASHSCOPE_BASE_URL", DEFAULT_BASE_URL),
        router_model=_value(source, "CLAIMGUARD_ROUTER_MODEL", "qwen3.8-flash"),

- [ ] **Step 3: 实现 provider**

```python
from agents import RunConfig
from agents.models.interface import Model, ModelProvider
from agents.models.openai_responses import OpenAIResponsesModel
from openai import AsyncOpenAI


class QwenModelProvider(ModelProvider):
    def __init__(self, settings: AgentRuntimeSettings):
        self._client = AsyncOpenAI(
            api_key=settings.api_key,
            base_url=settings.base_url.rstrip("/"),
        )

    def get_model(self, model_name: str | None) -> Model:
        if not model_name or not model_name.strip():
            raise AgentProviderError("Agent model name must be non-empty")
        return OpenAIResponsesModel(
            model=model_name.strip(),
            openai_client=self._client,
        )


class AgentProviderError(ValueError):
    pass


def build_run_config(
    provider: ModelProvider,
    tracing_enabled: bool,
) -> RunConfig:
    return RunConfig(
        model_provider=provider,
        tracing_disabled=not tracing_enabled,
    )
```

SDK API 若在锁定版本中导出相同类型的路径不同，只允许调整 import 路径，公共接口和测试断言保持不变。

- [ ] **Step 4: 实现脱敏审计接口**

```python
@dataclass(frozen=True)
class AuditEvent:
    event_type: str
    tenant_id: str
    session_id: str
    user_id: str
    details: dict[str, object]


class AuditSink(Protocol):
    def record(self, event: AuditEvent) -> str: ...


class InMemoryAuditSink:
    def __init__(self):
        self.events: list[AuditEvent] = []

    def record(self, event: AuditEvent) -> str:
        self.events.append(event)
        return f"audit-{len(self.events):06d}"


class JsonlAuditSink:
    def __init__(self, path: Path):
        self._path = path

    def record(self, event: AuditEvent) -> str:
        audit_id = f"audit-{uuid4().hex}"
        self._path.parent.mkdir(parents=True, exist_ok=True)
        payload = {
            "audit_id": audit_id,
            "recorded_at": datetime.now(timezone.utc).isoformat(),
            **asdict(event),
        }
        with self._path.open("a", encoding="utf-8") as stream:
            stream.write(json.dumps(payload, ensure_ascii=False) + "\n")
        return audit_id
```

`AuditEvent.__post_init__()` 递归检查 `details` 中的字典键，拒绝大小写不敏感且包含 `api_key`、`authorization`、`credential`、`token` 或 `secret` 的键。`recorded_at` 使用 UTC ISO 8601。v0.5 不记录原始客户消息。CLI 默认使用 `.claimguard/audit.jsonl`；该目录已在 `.gitignore` 中忽略。

`CopilotRuntime.run_turn()` 必须：

```text
1. 用 tenant_id + session_id 读取 ConversationState。
2. 没有状态时从 Router 开始并把当前消息作为字符串输入；有状态时从 `agents.by_name[current_agent]` 开始，将新消息追加到保存的 `input_items` 后输入。

6. 仅接受 `CopilotAgentOutput`；按其 `status` 和 `draft` 构造 `CopilotTurnResult`。
7. SDK、模型或 Handoff 错误记录不含异常正文的 `run_failed` 事件，并统一返回 `human_takeover`。
```

所有审计通过 `context.audit_sink` 写入。若 Session 中的 `user_id` 与当前上下文不一致、保存的 `current_agent` 不在 `agents.by_name` 中，或最终输出不是 `CopilotAgentOutput`，记录 `run_failed` 并直接返回 `human_takeover`。`CopilotTurnResult` 和审计内容都不得包含底层异常正文。

def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        description="Run the ClaimGuard AI customer service Copilot."
    )
    parser.add_argument("--tenant-id", required=True)
    parser.add_argument("--user-id", required=True)
    parser.add_argument("--session-id", required=True)
    parser.add_argument("--index", required=True)
    parser.add_argument("--audit", default=".claimguard/audit.jsonl")

    return parser


async def execute_turn(args: argparse.Namespace) -> CopilotTurnResult:
    settings = load_agent_runtime_settings()
    provider = QwenModelProvider(settings)
    run_config = build_run_config(provider, settings.openai_tracing_enabled)
    audit_sink = JsonlAuditSink(Path(args.audit))
    context = CopilotContext(
        tenant_id=args.tenant_id,
        session_id=args.session_id,
        user_id=args.user_id,
        knowledge_index=load_knowledge_index(args.index),
        embedding_client=DashScopeEmbeddingClient(),
        audit_sink=audit_sink,
    )
    policy_tool = build_search_policy_tool()
    agents = build_copilot_agents(settings, policy_tool)
    runtime = CopilotRuntime(
        agents=agents,
        run_config=run_config,
        session_store=InMemorySessionStore(),
    )
    return await runtime.run_turn(context, args.message)


def main(
    argv: list[str] | None = None,
    turn_executor: TurnExecutor = execute_turn,
) -> int:
    args = build_parser().parse_args(argv)
    if not Path(args.index).is_file():
        print("Knowledge index not found", file=sys.stderr)
        return 2
    try:
        result = asyncio.run(turn_executor(args))
    except (
        AgentSettingsError,
        AgentProviderError,
        EmbeddingError,
        KnowledgeError,
        OSError,
    ):
        print("Copilot request failed", file=sys.stderr)
        return 2
    print(json.dumps(asdict(result), ensure_ascii=False, indent=2))
    return 0
