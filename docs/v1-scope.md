# ClaimGuard AI V1 范围

ClaimGuard AI 聚焦保险文字客服，明确不包含电话、ASR、说话人分离、OCR、视频、智能外呼和音频质检。

## 产品能力

V1 包含两个核心工作流：

1. 客服 Copilot
   - 读取正在处理的客户消息。
   - 识别客户意图。
   - 检索相关保单知识。
   - 建议有依据的回复。
   - 标出客服应避免的高风险措辞。

2. 智能质检
   - 读取已完成文字对话。
   - 为服务质量评分。
   - 运行语义、流程和知识依据检查。
   - 展示证据、违规规则 ID、引用条款和改进回复。

## 技术形态

首个实现应以工作流为中心：

```text
Router
  -> 知识工作流：意图、检索、引用依据
  -> QA 工作流：规则选择、判定、证据、评分
```

V1 不需要很多 Agent。业务任务足够结构化，小型工作流图比过大的多 Agent 设计更清晰，也更易测试。
